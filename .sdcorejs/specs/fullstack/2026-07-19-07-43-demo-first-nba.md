# Demo-first NBA - Approved Scope

## Mục tiêu

Đưa luồng Sales Copilot có thể trình diễn ổn định lên Angular Core UI trong thời gian ngắn nhất bằng dữ liệu profile seed, recommendation snapshot, assessment rules và NBA API hiện có.

## Luồng demo bắt buộc

`Đăng nhập → Call list → Chọn khách → Xem Top 2 + hook/explain → Xem assessment → Ghi chú → Gửi feedback → Xem audit/version`

## Trong phạm vi

- Angular Core UI cho call list và customer detail.
- Recommendation snapshot, hook/explain, version, staleness và assessment 3/6 tháng.
- Ghi chú, feedback và audit trace qua API hiện hữu.
- Quyền sale/manager/admin, focused regression tests, development build và deploy dev.
- Sửa regression staleness nếu focused test xác nhận lỗi aggregate SQL.

## Ngoài phạm vi trước demo

- Live batch M1-M8, AG1-AG6, local LLM, mini-pipeline, outcome/retrain và RAG cases.
- Admin call-list assignment, schema/migration hoặc dependency mới.
- Không mô tả recommendation seed/rule-based như kết quả live LLM.

## Acceptance criteria

1. Người dùng đăng nhập và mở được Sales Copilot từ menu Angular Core UI.
2. Call list theo ngày hiển thị khách trong đúng authorization scope cùng Top 2 recommendation hiện có.
3. Customer detail hiển thị recommendation, hook/explain, version, staleness, assessment và audit.
4. Người dùng hợp lệ lưu được call note và feedback; rejected bắt buộc có lý do.
5. UI có loading/error/empty/forbidden states và không phụ thuộc localhost trong hosted build.
6. Focused backend/frontend tests, Angular development build, E2E critical journey và deploy smoke pass.
