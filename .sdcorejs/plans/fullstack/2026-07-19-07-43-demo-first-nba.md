## Tasks

### Phase 1 - Ổn định dữ liệu và API

1. COMMAND focused backend/profile-seed tests và read-only smoke các endpoint NBA bằng dữ liệu hiện có - xác nhận demo fixture, authorization scope và API contract trước khi dựng UI.
2. EDIT `backend/src/modules/nba/nba.service.ts`; EDIT `backend/test/nba.service.spec.ts` - viết regression test và chỉ sửa aggregate staleness nếu test xác nhận lỗi nhân dư nợ do join nhiều bảng.

### Phase 2 - Angular Core UI

3. CREATE `frontend/src/app/core/api/nba.models.ts`; CREATE `frontend/src/app/core/api/nba-api.service.ts`; CREATE focused API specs - map các endpoint NBA hiện hữu mà không đổi backend contract.
4. CREATE `frontend/src/app/features/nba/calllist/**` - trang call list theo ngày, Top 2, score, empty/error/loading states và link tới khách hàng.
5. CREATE `frontend/src/app/features/nba/customer-detail/**` - recommendation snapshot/version, hook/explain, staleness, assessment 3/6 tháng, rule status, notes, feedback và audit trace.
6. EDIT `frontend/src/app/app.routes.ts`; EDIT `frontend/src/app/layout/main-layout.component.ts`; EDIT `frontend/src/app/core/auth/permission-map.ts` - thêm Sales Copilot menu/routes và quyền sale/manager/admin.

### Phase 3 - Verification và deploy dev

7. COMMAND focused backend/frontend tests, Angular lint/development build, critical E2E và `git diff --check` - sửa finding trong phạm vi cho tới khi pass hoặc báo blocker cụ thể.
8. COMMAND scoped commit, push `dev`, theo dõi CI/deploy và live smoke Keycloak, NBA routes/actions, console và health endpoints - chỉ ship sau verify-before-done.
